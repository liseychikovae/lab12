# lab12

Лабораторная работа Лисейчиковой Екатерины

## Отчет по лабораторной работе XII

### Тема

Итоговое оформление серии лабораторных работ.

### Цель работы

Цель работы - собрать итоговую конфигурацию проекта, CI и отчет по лабораторным 3-12.

### Используемое окружение

- основной целевой сценарий: Linux;
- язык: C++11;
- система сборки: CMake;
- дополнительные инструменты добавляются по теме конкретной лабораторной;
- персональные токены и временные адреса не сохраняются в репозитории.

### Структура проекта

- `formatter_lib` - базовая статическая библиотека форматирования;
- `formatter_ex_lib` - расширенная библиотека, использующая `formatter`;
- `solver_lib` - библиотека для решения квадратного уравнения;
- `hello_world_application` - демонстрационное приложение;
- `solver_application` - приложение для вывода корней уравнения;
- `tests` - модульные тесты, начиная с lab05;
- `docs` и `scripts` - дополнительные материалы поздних лабораторных.

### Ход выполнения

- добавлен итоговый отчет `docs/final_report.md`; 
- добавлен шаблон GitHub Actions workflow `workflow_examples/ci.yml`; 
- после переноса в `.github/workflows` workflow собирает проект и запускает тесты на Ubuntu;
- в репозитории сохранены Docker, Vagrant, release и ngrok-материалы;
- README оформлен как финальный подробный отчет.

### Команды для проверки

```bash
cmake -S . -B _build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=ON
cmake --build _build
ctest --test-dir _build --output-on-failure
bash scripts/package_release.sh
```

### Домашнее задание

Домашнее задание выполнено внутри этого же репозитория. Подробное описание вынесено в `HOMEWORK.md`.

Кратко по выполнению:

- финальная структура показывает весь путь проекта от CMake до публикации артефактов;
- CI использует Ubuntu, что соответствует Linux-совместимой проверке;
- документация по Docker, Vagrant и ngrok остается внутри репозитория;
- итоговый отчет перечисляет, какие навыки закрыты каждой лабораторной.

### Результат

Финальный репозиторий объединяет все наработки и может использоваться как итоговая сдача серии работ.
